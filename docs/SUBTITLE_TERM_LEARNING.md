# 字幕の語の学習（キャラ別・task-243）

正本: [現行・到達仕様 §3.3-3](AUTOCLIPPER_CURRENT_AND_TARGET_SPEC_2026-09-25.md)の例外（2026-11-06承認）。
全面的な字幕の自動修正ではない。人が実際に直した語と完全に同じ文字列だけを、次回の字幕生成時に置き換える。
字幕の確認・最終修正は人が行う。Codexは使わず、新しいworker・キュー・DBテーブルも追加しない。

## 学ぶもの
- 字幕確認の保存のたび（`write_subtitle_review`）に、人が直した行の「元の文字起こし→直した文字」を文字単位の差分で取り、
  置換になった部分だけを「元の語→直した語」として数える。挿入・削除、1文字だけ、空白を含む、20文字を超える差は語として扱わない。
- 数えるのはジョブごとの現在の状態で、保存し直しても二重に数えない。人が後で直し直せば、そのジョブの数が更新される。
- キャラ（`characterPresetName`）ごとに `storage/subtitle_terms/<キャラ名のハッシュ>.json` へ保存する。
  キャラはレビュー文書の `characterPresetName` に持ち、キャラ設定の適用時に更新する。持たない古い文書は、保存時にジョブの設定（`characterPresetName`）から補う。保持は最新300ジョブ。

## 置換が有効になる条件（すべて）
1. 同じ直しが3回以上。2本以上の動画にまたがるか、1本だけなら5回以上。
2. 同じ語の直し先が複数あるときは、最多の直し先が全体の80%以上。
3. 直さずに残した例（同じ語が最終字幕に残っていた回数）を含めて、直した割合が80%以上。
4. 直した結果を人が元の語へ戻した回数が2回未満。
5. 「使わない」にした語ではない。

## 適用
- 新しいジョブの字幕レビューを作る直前（`run_autoclipper_job`）に、そのキャラの有効な語を文字起こしへ1回だけ置換する。
  長い語を先に、1パスで置換するため、置換結果が別の置換に使われない。単語ごとの時刻（words）も同じ置換で更新し、
  語の開始時刻と、まとめた語の終了時刻を保つ。更新後の単語が字幕と一致しない場合は単語時刻を捨てる（行の時刻は変えない）。
- 置換した行は人の修正（`edited`）として数えない。置換した内容は `outputs/<job>/learned_subtitle_terms.json` に残る。
- 失敗しても元の文字起こしで続け、ジョブを止めない。既存のジョブ・手動ワークフローの字幕は変えない。

## 画面・API
- 設定画面の「字幕の語の学習（キャラ別）」に、キャラごとの語・修正回数・状態を表示し、語ごとに「使わない／また使う」を選べる。
- GET `/api/subtitle-terms`、POST `/api/subtitle-terms/{characterId}/disable|enable`（`{src, dst}`、既存のOrigin確認を適用）。

## 未確認・制限
- 効果（字幕の直しが減るか）は実運用で未確認。置換の誤りは、キャラ別の一覧から語ごとに止められる。
- 直さずに放置された字幕（確認していない行）は「残した」とは数えない。確認済みの動画で直した語だけが学習の材料になる。
- 意味・文脈・タイミングの補正、新しい語の提案は行わない。
