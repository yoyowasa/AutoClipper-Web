# 制作属性の独自集計と制作ヒント（統合④）

task-234では従来の初期7日属性集計に加え、`choiceHistory` の出所・方針版・設定別の
30日評価を同じ保存先に追加した。[定時実行・30日評価](INTELLIGENCE_SCHEDULING_EVALUATION.md)を参照。
7日の集計・改善試験は途中評価として残し、30日目標の判定と混同しない。

## 独自集計

設定画面の自己分析欄に「独自集計」として表示する。YouTube公式の集計ではなく、改善効果・因果関係を証明しない。
対象は自チャンネルの制作記録と結び付いた動画。曖昧な記録ファミリー、最新記録と不一致の結び付き、
有効な初期7日がない動画、YouTubeの形式と制作記録の形式が違う動画は対象外とし、件数と理由を返す。

- 指標は公開翌日から7暦日（America/Los_Angeles）のAPI期間集計：views、averageViewPercentage、averageViewDuration、likes、subscribersGained。
- 現行の指標定義版・タイムゾーンに一致する7日間の公式レポートだけを比較し、異なる定義・未知の形式を混ぜない。
- 日ごとの平均を再平均しない。動画ごとの観測値の中央値、指標ごとの観測件数、同じチャンネル×形式の中央値、
  その中央値に対する比を計算する。比較先には制作記録が未結合の自チャンネル動画も含む。
- 欠損は0にしない。比較先の中央値が0なら比はnull（BASELINE_ZERO）、欠損もnullと理由を残す。
- キャラ×形式を基準に、尺・フック映像・フック文言・タイトルintent・postMetadataSource・openingScoreを属性別に分ける。
  属性をすべて掛け合わせたグループではない。同じ動画が複数行に入るため、件数を合算しない。
- 尺は本編のみ。Shortsは`<30 / 30–45 / 45–60 / 60–75秒`、設定で75秒を超えるものは`>75`も用意する。
  通常は`<3 / 3–6 / 6–10 / 10–20 / 20分以上`。各境界は左を含み右を含まない（Shortsの75秒は60–75に含む）。
  冒頭点は`0–5 / 5–10 / 10–15`（15を含む）、不明・範囲外は別表示。
- 5本未満またはviewsの観測が5本未満ならデータ不足。結び付き0本でも登録済みキャラと固定属性の空グループを返す。
- `production_aggregates`テーブルはcreate_allで追加。分析開始時に計算・保存し、画面に集計日時を表示する。
  APIは`GET /api/intelligence/channels/{id}/production-aggregates`。未保存/期限切れならローカル計算だけで返す。
  API・集計にGoogle/Codex呼び出しはなく、動画タイトルも保存しない。
- 保存期間は元の統計の最短期限まで（最大36か月、extended_storage=falseなら30日）。workerの既存保守処理で期限切れを消す。

## Codexが作る制作ヒント

自己分析の入力へ十分な集計グループを加え、`performance_hints`を返させる。旧Reviewにはなくてよく空配列として読む。
入力は件数順で最大40グループ・集計部分80,000文字、根拠動画IDは各100件まで。省略グループ数・省略ID数を明記し、task-216の入力予算も維持する。
ヒントはキャラ×形式ごと最大5件、全体最大50件。targetはselection/title_hook、文は日本語1〜2文、最大400文字。
グループID・実際の件数・キャラ/形式・根拠動画ID・confidenceを返し、サーバーが照合する。
5本未満の観測しかない指標を根拠にしないよう指示する。データ不足グループ、架空のID/件数・別キャラ/形式の根拠はサーバーで拒否する。
動画タイトル/URLの引用も拒否する。問題のあるヒントだけを除外し、既存の所見・提案の検証は維持する。
0件は正常であり、少ないデータから無理に作らない。

返答スキーマが変わるため、launcherのchannel_self_analysisの指紋だけ更新する。
**反映時にはホスト側Codex中継の再起動が必要**。他の依頼種別の指紋・モデルは変更しない。

## 次のジョブへの利用

キャラ設定「実績ヒントを使う」（usePerformanceHints、既定ON）をJobSettingsへ引き継ぐ。
同じキャラ/形式の最新の成功分析のヒントを参照し、期限切れ・接続解除・根拠動画の結び付き解除後は利用しない。
同じチャンネルの古い分析へは戻らず、最新の成功分析がヒント0件なら0件のまま。
選定は話題選定・境界決定、タイトル/フックは自動生成と字幕確認画面からの生成で使う。
入力には「過去の投稿実績からの参考情報（決まりではない）」と、字幕根拠・本数・尺・既存の検証を優先する説明を付ける。
ヒントなし/OFF/期限切れではフィールドも説明文も追加せず、変更前mainのプロンプトと完全一致する。

利用したanalysisId・生成日時・期限・text・target・形式を選定サマリー、タイトル/フック入力、
制作記録の任意項目performanceHintsへ残す。制作記録は制作時の履歴で、YouTube統計を書き込まない。
ヒントを使った結果の効果は未検証。実投稿での検証は別途行う。
