# チャンネル分析と改善試験（task-218）

## 画面

`/intelligence`（チャンネル指定: `?channel=<id>`）に、設定画面の「分析画面へ」から移動する。
設定画面には接続・同期・分析開始、最新分析の要約を残す。分析画面には次を置く。

- チャンネル、全体・ショート・通常の切替、直近28日と前28日の比較、56日の日別グラフ。
- 動画の期間値・初期7日、制作記録、該当する独自集計グループ。
- 最新の自己分析と履歴、所見・提案から根拠動画への移動、除外件数・理由、制作ヒント。
- 提案の採用、改善試験の編集・対象動画の選択・削除。

ページ閲覧・形式切替・「保存済みデータを読み直す」では、Googleへの同期やCodex分析を開始しない。
同期・分析は従来の明示操作とバックグラウンド処理を使う。試験の採用も選定・タイトル生成を自動変更しない。
任意項目の「動画作成画面へ採用中の変更点を表示」は今回は含めない。

## 値の区別と欠損

| 表示 | 出所・扱い |
| --- | --- |
| 全体の28日・日別 | 最新の成功/一部成功同期と期間が一致するYouTube Analyticsの公式値（青） |
| 形式別の28日・日別 | 保存済み動画×日別値の加算可能な指標のみを合計する独自集計（紫） |
| 動画の28日・初期7日 | 対応する期間の公式レポート。日別の平均視聴率・時間を再平均しない |
| 制作属性別 | task-217の独自集計・中央値と同形式比。5本未満はデータ不足 |

現行の同期は形式別のチャンネル公式期間値・日別値を取得していない。そのため形式別に公式値を装った合計は表示しない。
対象は同チャンネルのメタデータが有効な動画。形式不明・取得されていない動画・削除動画を含まないことを明示する。
公開前の日は動画×日の期待件数から除く。それ以外の未返却を0とはみなさない。

動画×日の一部が欠ける場合、全期間の値は「未取得」とし、理由・返却件数・返却分だけの小計を別に表示する。
日別グラフも、小計は橙の点線、欠損は線を切る。APIが実際に返した0は0と表示する。
期間、取得日時、タイムゾーン、出所を表示し、期限切れ・定義版/タイムゾーンの異なる行を使わない。
比較値を作れない原因として、初期7日未返却、形式不明/不一致、尺帯不明/不一致、指標未取得を区別する。

## 改善試験

採用時には、その分析・提案に対して1つの試験を作る。同じ提案の再採用は既存の試験を返す。
基準動画、変える1点、固定すること、主要指標、反証条件、確認方法を引き継ぐ。

対象動画は、有効な制作記録と結び付いた同チャンネルの動画で、基準より後の公開に限る。
形式や尺帯が違う場合も保存できるが、比較不可の理由を表示し、増減の判定は出さない。
比較には **公開翌日から7暦日（America/Los_Angeles）** の公式レポートだけを使う。
公開当日を含めず、UTC日付をそのまま日付として使わない。未返却の期間を日別値で補完しない。

尺帯はショートが30秒未満/30〜45秒未満/45〜60秒未満/60〜75秒/75秒超、
通常が3分未満/3〜6分未満/6〜10分未満/10〜20分未満/20分以上。
同形式・同尺帯で必要な公式値がある場合だけ主要指標の増加/減少/同値を表示する。
これは因果効果の判定ではない。公開時期・題材・流入・視聴者の違いは残る。

条件の編集では登録日時を更新し、公開後に登録・変更した試験を「事後記録」と表示する。
対象動画だけの紐付けでは登録日時を更新しない。編集は更新日時を照合し、競合を409で返す。
メタデータの期限切れ後も意図の編集・終了・削除は可能で、動画の新規指定には有効なメタデータが必要。

## 保存と保持

新しい `improvement_trials` テーブルに採用した制作上の意図と参照ID・日時・状態を保存する。
分析ID+提案IDは一意。動画・分析の行に外部キーを張らず、保持期限後も試験そのものは残す。
タイトル・観測値・比較結果の専用コピーは持たず、表示時に既存テーブルから読む。
採用して記録した文章とユーザーの編集は自前の試験メモとして保持する。

YouTubeの動画メタデータは30日、統計は既存設定の最大36か月の保持規則に従う。
保守処理前でも期限切れを読み出さず、取得できない基準・対象は未取得として表示する。
削除は試験の行だけを消し、動画・制作記録・分析・結び付けは消さない。

## 追加API

すべて `/api/intelligence/channels/{channel_id}` 以下。

| Method | Path | 用途 |
| --- | --- | --- |
| GET | `/dashboard?format=all\|shorts\|long` | 保存済み期間値・日別・動画詳細 |
| GET | `/analysis/{analysis_id}/evidence-videos` | 保存済みの根拠ID→動画ID |
| GET | `/trials` | 改善試験と現在の比較結果 |
| POST | `/analysis/{analysis_id}/proposals/{proposal_id}/adopt` | 採用・試験作成 |
| PUT | `/trials/{trial_id}` | 内容・対象動画・状態の変更 |
| DELETE | `/trials/{trial_id}` | 試験だけ削除 |

書き込みは既存のOrigin検証を使う。チャンネル・動画の所属を確認し、応答はno-storeとする。
